# Исходники макетов

Живой холст с макетами: https://claude.ai/artifact/QgkQMoDg37b86ZDn6KPU4D

Здесь лежат исходные файлы всех 25 экранов (`*.dc.html`) и раскладка холста (`canvas.json`).
Каждый экран — самостоятельный HTML-файл формата Design Component (редактор Claude Design).
Из этих же файлов собирается Android-прототип: `tools/build_prototype.py`.

## Что из макетов попадает в прототип

В сборке 37 экранов: 19 берутся из этих макетов, 18 свёрстаны вручную в `web/*.html`.

- AddCar, Cart, Wallet и Budget в прототипе заменены ручной вёрсткой (`web/addcar.html`, `web/cart.html`,
  `web/wallet.html`, `web/budget.html`); макеты остаются на холсте как эталон.
- Reminders и OneTapTO в сборку не входят: их заменил единый сценарий ТО (`web/to.html`),
  старые адреса `#Reminders` и `#OneTapTO` перенаправляются на `#TO`.

## Договорённости для правок макетов

- **Без заглушек в квадратных скобках.** Названия сервисов, магазинов и адреса — выдуманные,
  правдоподобные, без реальных брендов и сетей (например, автосервис «Мотор-Профи», магазин «Запчастино»).
  Демо-цены помечаются «демо-цена». Вместо [ФОТО] и [QR] — линейные значки и SVG-узор.
- **Даты относительные.** Дата, которая должна быть «через N дней» от сегодня, оборачивается в
  `<span data-rel-day="N" data-date-fmt="…">`; `web/app.js` при запуске подставляет актуальную дату.
  Форматы: `d` — число, `MMMM` — «ноября», `MMM` — «нояб», `wd` — «пн», `yyyy` — год
  (например, `wd, d MMMM` → «пн, 9 ноября»); `data-date-case="upper"` — заглавными. N может быть отрицательным.
- **Кнопка «Назад»** — белый круг 44 px с рамкой `#E2DED6`, `aria-label="Назад"`; переход на предыдущий
  экран делает `web/app.js`, `href` — запасной адрес, если экран открыт первым.
- Тап-зоны не меньше 44 px, без эмодзи и градиентов (кроме затухания края у прокручиваемых лент).
