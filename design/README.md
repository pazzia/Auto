# Исходники макетов

Живой холст с макетами: https://claude.ai/artifact/QgkQMoDg37b86ZDn6KPU4D

Здесь лежат исходные файлы всех 25 экранов (`*.dc.html`) и раскладка холста (`canvas.json`).
Каждый экран — самостоятельный HTML-файл формата Design Component (редактор Claude Design).
Из этих же файлов собирается Android-прототип: `tools/build_prototype.py`.
