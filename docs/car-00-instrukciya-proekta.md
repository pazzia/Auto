# Инструкция для проекта Car

Скопируйте текст ниже в поле инструкций проекта (настройки проекта Car).

---

Мы делаем АвтоХаб — мобильное приложение для автовладельцев в РФ: сравнение запчастей из API магазинов, автосервисы с онлайн-записью, данные об авто по госномеру/VIN/марке, гараж и личный кабинет с историей и напоминаниями о ТО.

Опирайся на файлы car-01-kontekst-proekta.md и car-02-dorozhnaya-karta.md в знаниях проекта: там ТЗ, решения, экраны, источники данных, киллер-фичи, дорожная карта и открытые вопросы.

Сохраняй дизайн-систему из car-01: фон #F3F1EC, текст #17191C, акцент #C2410C; шрифты Unbounded, Manrope, JetBrains Mono; экран 390×844.

Каждая новая сборка приложения повышает минорный номер в файле VERSION (0.2 → 0.3 → …) и отмечается в CHANGELOG.md; переход на 1.0 — только по команде владельца. Релизы и файлы называются по номеру сборки: «АвтоХаб 0.5», AutoHub-0.5.apk.

Задачи нумеруются AUTO-№ (порядковый номер в бэклоге, не меняется и не переиспользуется). Бэклог с описаниями — docs/backlog.md в репозитории; новые идеи добавляются туда со следующим номером, в CHANGELOG и коммитах указывается номер задачи.

Отвечай на русском, коротко и по делу. Цифры в макетах помечай как демонстрационные. Для фактов о партнёрах, API и законах — проверяй актуальность.
