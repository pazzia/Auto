## Что делать первым

1. Перевыпустить ключ подписи, хранить в GitHub Secrets, удалить `app/autohub-prototype.keystore` и пароли из репозитория (тестировщикам — одна переустановка).
2. Публиковать release-сборку (не debuggable), `allowBackup="false"` или правила без `app_webview`.
3. CI: `permissions: contents: read` по умолчанию, запись — только задаче релиза; actions по SHA; `persist-credentials: false`; не публиковать OCR-текст в `ci-ocr-reports`.
4. `car.js` `loadGarage`: сохранять гараж сразу при переносе с 0.4 — иначе данные пишутся под случайный id и теряются.
5. Разбор наряда: итог при скидке, пробег `125.400`, «Дата приёма», «К оплате N позиций».
6. Напоминания: пересоздавать после перезагрузки (BOOT_COMPLETED), точные будильники для парковки.
7. WebView: `configChanges` + `onPause/onResume/destroy`, сохранять `documentCameraUri` — иначе снимок теряется при смене темы.
8. Общие CSS-ошибки: `.kv b{text-align:right}`, сетки `1fr 1fr` без `minmax(0,1fr)`, `.to-row` без flex.

## Безопасность и выпуск

- **[критично]** `app/build.gradle.kts:28-39` — ключ подписи и пароли в публичном репозитории. Любой может подписать APK `ru.autohub.app` с большим versionCode, и Android поставит его поверх, получив документы, VIN, координаты и выданные разрешения.
- **[высокая]** `build-apk.yml:58,121` — в релиз уходит `assembleDebug`: `debuggable=true`, работают `run-as`, `adb backup`, отладка WebView через chrome://inspect.
- **[высокая]** `build-apk.yml:13-14` — `contents: write` для всех задач, сторонние actions по тегам (`android-emulator-runner@v2`, `action-gh-release@v2`, `setup-gradle@v4`), токен остаётся в `.git/config`. Вместе с ключом — цепочка подмены релиза.
- **[средняя]** `AndroidManifest.xml:17` — `allowBackup="true"` без правил: IndexedDB с оригиналами нарядов уходит в Google Drive, хотя интерфейс обещает «документы никуда не отправляются».
- **[средняя]** Персональные данные открытым текстом в localStorage/IndexedDB (для прототипа допустимо, но вместе с debuggable и бэкапом утекают без root).
- **[средняя]** `RealDocumentAcceptanceTest.kt:76` — полный OCR-текст пишется в публичную ветку `ci-ocr-reports`; один реальный наряд в `acceptance/` — и ФИО, VIN, телефон публичны.
- **[низкая]** `MainActivity.kt:101` — `allowFileAccess=true` не нужен; мосты открыты всем фреймам, нет CSP. Лучше `WebViewAssetLoader`.
- **[низкая]** `NativeHttp.kt:30-39` — редиректы уводят с белого списка хостов, ответ читается без ограничения размера.
- **[низкая]** `MainActivity.kt:112` — снимки документов лежат в `cacheDir` до 24 ч и не удаляются при удалении аккаунта.
- **[низкая]** `ui.js:10` — `esc()` не экранирует `'`; отдельные значения из localStorage вставляются без экранирования (только self-XSS).
- **[низкая]** Gradle: нет `verification-metadata.xml` и `distributionSha256Sum`; JitPack; Google Fonts раскрывают IP при каждом запуске.

В порядке: XSS через OCR-текст и vPIC не найден (всё через `esc()`), FileProvider узкий, ReminderReceiver не экспортирован,
cleartext выключен, модели OCR закреплены по коммиту и SHA-256 и сверяются на телефоне, других секретов в истории нет.

## Нативный слой

- **[высокая]** Напоминания о сроках документов теряются после перезагрузки: нет BOOT_COMPLETED, при запуске ничего не переставляется, ОСАГО не ставится вообще.
- **[высокая]** `MainActivity.kt:292` — `setAndAllowWhileIdle` неточный: напоминание «за 10 минут до конца парковки» может прийти через 40 минут после.
- **[высокая]** `AndroidManifest.xml:26` — неполный `configChanges`: тёмная тема, шрифт, складной экран пересоздают Activity; черновик OCR и снимок с камеры теряются, старый WebView не уничтожается и продолжает опрашивать GPS.
- **[средняя]** Нет `webView.onPause/onResume` — JS и GPS работают в фоне.
- **[средняя]** `OfflineOcrEngine.kt:134` — «один проход для больших документов» считает файлы, а не страницы: PDF на 10 страниц получает 30 проходов.
- **[средняя]** `OfflineOcrEngine.kt:59,62` — фото 50/108 Мп отклоняются, 24 Мп уменьшается до 1500 px и теряет мелкий текст.
- **[средняя]** `allowBackup` (см. выше).
- **[средняя]** Android 13+: при запрете уведомлений JS не узнаёт, что напоминание не придёт.
- **[низкая]** Отмена OCR может потеряться до конца прохода; EXIF-ориентации 5 и 7 развёрнуты на 180°; не проверяется результат `restoreState()`; пул потоков `NativeHttp` не закрывается; id напоминаний — 900 значений, коллизии; приёмочный тест ловит `Throwable` и почти не может упасть.

Контракт мост ↔ JS (имена методов, JSON, колбэки) полностью совпадает с `web/*.js`.

- **[средняя]** `document-parser.js:200` — «К оплате 2 позиции на сумму 3 000,00» → итог 2.
- **[средняя]** `car.js:125` — повторное добавление по тому же VIN стирает госномер и регион.
- **[средняя]** `car.js:131` — удаление машины не удаляет её историю, заправки, заказы, чат и документы, хотя интерфейс это обещает.
- **[средняя]** `fuel.js:106-107` — при 10 заправках стирается фото только что сфотографированного чека.
