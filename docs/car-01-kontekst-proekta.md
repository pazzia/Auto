# АвтоХаб (проект Car) — полный контекст

Состояние на 26 сентября 2026. Документ собран из переписки с Claude, чтобы продолжать работу в проекте без потери контекста.

## 1. Что за продукт

Мобильное приложение для автовладельцев в России, рабочее название **АвтоХаб**. Цель — стать приложением, которое открывают первым по любому вопросу о машине.

### Исходное ТЗ (4 пункта)

1. Агрегировать данные из каталогов и витрин магазинов запчастей с открытыми API: запчасти и цены. API продающих компаний будут у владельца проекта.
2. Агрегировать автосервисы с онлайн-записью из открытых API (2ГИС, Яндекс и др.).
3. Подтягивать информацию об автомобиле из открытых источников по трём параметрам: госномер, VIN, выбор марки/модели.
4. Личный кабинет: автомобиль, история обслуживания, история посещений, напоминания о регламентных работах, запись на ТО в сервис, покупка запчастей.

## 3. Дизайн

**Стиль:** тёплый светлый фон, графитовый текст, один оранжевый акцент. Никаких градиентов и эмодзи.

- Цвета: фон `#F3F1EC`, поверхность `#FFFFFF`, текст `#17191C`, вторичный текст `#5B5F66`, линии `#E2DED6`, акцент `#C2410C` (тёмный `#9A3412`, светлый `#FCEBDF`), «хорошо» `#0F6B3A` / `#DDF0E4`, синий `#1B3F99` / `#DCE6FB`.
- Шрифты: Unbounded (заголовки), Manrope (текст), JetBrains Mono (артикулы, VIN, госномера).
- Экран телефона 390×844, скругления 12–18 px, кнопки от 44 px высотой.
- Нижняя навигация: Гараж · Запчасти · Сервисы · Корзина.

### Экраны на холсте (7 рядов)

1. **Автомобиль и ЛК:** 1.1 Добавить авто (госномер / VIN / марка), 1.2 Гараж (ЛК), 1.3 Регламент ТО, 1.4 История, 1.5 ТО в один тап.
2. **Запчасти:** 2.1 Поиск, 2.2 Результаты (оригинал и аналоги), 2.3 Цены продавцов (итог с доставкой, надёжность), 2.4 Сравнение деталей, 2.5 Корзина (по продавцам, подсказка «собрать у одного»).
3. **Автосервисы:** 3.1 Список и карта (рейтинги 2ГИС и Яндекса, «цена в норме»), 3.2 Запись (честный ценник, работы из регламента), 3.3 Запись подтверждена.
4. **Частота:** 4.1 Штрафы, 4.2 Смена шин, 4.3 Страховка, 4.4 Помощь на дороге.
5. **Деньги:** 5.1 АвтоХаб Плюс, 5.2 Баллы и копилка, 5.3 Бюджет владения.
6. **Доверие:** 6.1 Ремонт онлайн, 6.2 Гарантии.
7. **Данные и люди:** 7.1 Паспорт авто, 7.2 Семейный гараж, 7.3 Владельцы модели.

Демо-машина во всех макетах: Kia Rio IV, 2019, 1.6 MPI, АКПП, А 123 ВС 177, пробег 58 400 км. Цифры на экранах демонстрационные; цены подписки и хранения шин — плейсхолдеры `[ЦЕНА]`, названия сервисов — `[Название]`.

## 4. Android-прототип (сборка 0.5)

- С 0.5: окно приветствия со входом и регистрацией (любые данные), личный кабинет (вкладка «Профиль»):
  профиль, управление машинами, сервисы, настройки, выход, номер сборки. Все экраны живые на демо-данных.

- Нумерация сборок: файл `VERSION` в репозитории; каждая новая сборка повышает минорную версию (0.2 → 0.3 → …),
  переход на 1.0 — по решению владельца. Номер виден внизу экрана «Мой гараж» и в versionName APK.

- С 27.09.2026 код в репозитории https://github.com/pazzia/Auto. Все вызовы API идут через `web/api.js`
  и по умолчанию отвечают заглушками (демо-данные); контракт — `docs/api.md`.
- Экран автосервисов показывает статическую схему Подмосковья с метками сервисов (демо-позиция — Красногорск).
- Веб-версия публикуется на GitHub Pages, APK — артефакт Actions.

Ранее (0.3):

- Нативная оболочка на Kotlin (WebView) + HTML-прототип всех 25 экранов в `app/src/main/assets/www/`.
- `NativeHttp.kt` — мост для запросов к открытым API из нативного кода (без CORS), белый список хостов (сейчас только `vpic.nhtsa.dot.gov`).
- `web/api.js` — слой API и заглушки; `web/car.js` — добавление авто; `web/services.js` — сервисы и карта; `web/addcar.html` — экран; `tools/build_prototype.py` собирает `index.html` из файлов макета (`design/*.dc.html`).
- Реальными данными работает только добавление авто; остальное — демо.
- Сборка APK: Android Studio (Build → Build APK) или GitHub Actions (workflow в проекте, артефакт `autohub-debug-apk`).
- iOS: APK не ставится. Варианты — веб-версия на экран «Домой», Xcode со своим Apple ID (7 дней), TestFlight/App Store ($99/год; регистрация из РФ может быть затруднена). Для рабочей версии рекомендован кроссплатформенный стек (Flutter или Kotlin Multiplatform).

## 5. Данные об автомобиле

### Что уже работает (бесплатно)

- **VIN:** проверка формата (17 символов, без I, O, Q) → локальная расшифровка по коду производителя (WMI) и модельному году → NHTSA vPIC (бесплатно, без ключа). vPIC содержит машины для рынка США, поэтому для авто российской сборки обычно определяются марка, завод, год, а модель уточняется вручную.
- **Госномер:** проверка формата, сохранение в карточку. Бесплатной базы «номер → VIN» нет — приложение просит VIN из СТС.
- **Марка/модель:** справочник популярных в РФ марок + модели из vPIC для остальных.

### Платные источники для рабочей версии

- Госномер → VIN, история регистрации, пробег, техосмотры (ЕАИСТО): AvtoVinCod, АвтоПроверка, Автокод для бизнеса, apipoint (пример цен: расшифровка VIN 1,10 ₽, пробег 1,10 ₽, данные ГИБДД по VIN 21 ₽, полный отчёт 50 ₽).
- Полная история (ДТП, залоги, ограничения): Автотека API (пакеты от 1000 отчётов), Автокод.
- Подбор запчастей по VIN: Laximo (45+ автопроизводителей, кроссы 3500+ брендов), Acat, NLA24.
- Официального открытого API ГИБДД нет; часть посредников — серые парсеры. Брать только поставщиков с договором и SLA, держать второго в резерве.
- Персональные данные: VIN и госномер сами по себе обычно не считают ПДн, но в связке с аккаунтом (телефон, имя) это ПДн → согласие, политика, серверы в РФ. Проверить у юриста.

## 6. Конкуренты и выводы

- **Агрегаторы запчастей** (Emex, Exist, Autodoc, ZZap): боли — доставка съедает выгоду, отказы по минимальной цене, подделки, непрозрачные продавцы.
- **Агрегаторы сервисов** (Uremont): заявка → сервисы присылают цены; комиссия с сервиса 400–1000 ₽ за заявку + 5% от ремонта (не более 3000 ₽). Запчасти не связаны.
- **Приложения сетей и CRM** (FIT SERVICE, АвтоДилер): запись и сервисная книжка только внутри своей сети.
- **Бортжурналы** (GarageGo, My Garage, Drom Гараж): всё вручную, нельзя купить или записаться.
- **Запад:** RepairPal (калькулятор справедливой цены + гарантия), Openbay/CarAdvise (сравнение смет, подписки со скидками).
- **Вывод:** никто не объединяет запчасти + сервисы + гараж. Это ниша АвтоХаба.
- **Важно:** лицензия 2ГИС запрещает API в закрытых коммерческих продуктах без индивидуальных условий; онлайн-запись в 2ГИС работает через CRM партнёров (например, YCLIENTS). Реальные слоты брать из API CRM автосервисов.

## 7. Киллер-фичи

### Первый список (отличие от конкурентов)

1. Итоговая цена «до двери» + индекс надёжности продавца — **в макетах**.
2. ТО в один тап: регламент → комплект → слот → доставка запчастей в сервис — **в макетах**.
3. Честный ценник на работы — **в макетах**.
4. Сравнение «свои запчасти против запчастей сервиса».
5. Антиподделка: рейтинг продавцов по возвратам, отметка официального дистрибьютора.
6. Сервисная книжка, которая заполняется сама (CRM, фото чеков).
7. ИИ-диагност по симптомам (+ OBD позже).
8. Ценовой радар.
9. Безопасная сделка.
10. Болячки модели и отзывные кампании по VIN.

### Второй список (удержание) — все 12 в макетах

- Частота: штрафы со скидкой 50%, сезонная смена шин, ОСАГО/КАСКО, SOS.
- Деньги: подписка «ТО по фиксированной цене», кэшбэк баллами, бюджет владения с копилкой.
- Доверие: ремонт онлайн с согласованием доп. работ, гарантия платформы 30 дней.
- Данные и люди: паспорт автомобиля с QR для покупателя, семейный гараж, советы владельцев той же модели.
- Принцип: удерживать выгодой и накопленной историей; выгрузку данных разрешить сразу.
